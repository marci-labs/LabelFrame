# Web 设计器原型（技术选型评估 · v2）

用于评估「Studio UI 层改用 Web 技术」的拖拽设计器原型。后端（WinHost / Core / Rendering / Server / AndroidHost）完全复用，原型通过 WinHost HTTP API 加载 / 保存模板与生成预览。

## 运行

1. 启动 WinHost（Log 模式即可）：
   ```powershell
   dotnet run --project src\LabelFrame.WinHost
   ```
2. 浏览器打开本目录 `index.html`（双击即可，无需服务器）。
3. 顶部填 WinHost 地址（默认 `http://127.0.0.1:53960`）→「连接」→ 可「加载」已有模板、「保存」、「预览」。

> 依赖库（Konva / JsBarcode / qrcode-generator）均已本地化，原型离线可打开；未连接 WinHost 时仍可本地设计。

## v2 改进（按用户反馈）

1. **视口缩放模型**：画布容器自动铺满视口（随窗口自适应）；Ctrl+滚轮只缩放画布内容（看整体 / 局部），鼠标位置保持；「适应窗口」一键铺满，「实际大小」= 1mm≈4px（可滚动），设计态与真实尺寸预览分离。
2. **条码 / 二维码实时渲染**：值（字段 Key 或固定值）变化立即在画布渲染真实条码 / 二维码（JsBarcode / qrcode-generator），可直接评估大小与位置；属性面板预留参数分组：条码（码制 / 底部文字 / 模块宽）、二维码（纠错级别 / 边距）。
3. **智能参考线**：拖动元素时自动吸附画布边缘 / 中心、其它元素边缘 / 中心，并显示红色参考线，方便拖两个文本框对齐顶部等。
4. **边框修正**：边框 = 矩形元素外框（描边），不再描文字（避免文字加粗）。
5. **控件精简**：控件栏只保留文本 / 条码 / 二维码；图片 / 线 / 容器不再提供入口（已有模板仍可加载显示，逻辑后续重做）。
6. **文本溢出模式**：每元素可配置「自动换行 / 超长截断 / 缩小字体」（缩小有最小字高，参考 BarTender Auto-Fit 与 Cleverence Label 的做法），避免内容溢出绘制范围。

## v3 改进（第二轮反馈）

1. **画布留白 + 标尺跟随**：画布实际大小 = 输入尺寸 + 四周 10mm 留白；标尺以 mm 为单位覆盖整个画布（0..宽+20 / 0..高+20），随画布一起移动/缩放，标签内容区边缘在标尺上以蓝色刻度标出。
2. **画布平移不越界**：中键拖拽平移时画布不会超出可视边界（clamp 到视口）。
3. **容器不再手动缩放**：默认画布铺满视口（随窗口自适应，无内容缩放）；「实际大小」按 **1mm = 8 点**（203dpi 打印比例）显示真实大小，可滚动 / 平移查看。
4. **文本溢出第四种模式**：「不限制高度」——按内容实际高度显示全部文字（观察真实占用）。
5. **修复拖入不可见（核心）**：`stage.scale` 只缩放绘制内容而 canvas 容器尺寸仍是逻辑像素，导致放大时画布内容被 canvas 裁剪（只有左上角可见，元素在裁剪区外看不到）。改为 **stage 尺寸 = 逻辑尺寸 × 比例尺**（canvas 真实放大，内容完整可见）；同时控件拖入坐标改为基于 `clientX/Y` 几何换算（HTML5 拖拽期间 Konva 无指针事件）。
6. **标尺与网格对齐**：标尺布局改为「左上角空块 + 顶标尺 + 左标尺 + 画布」，标尺 0 点与画布左缘对齐；网格覆盖整个画布（含 10mm 留白）并与标尺同比例缩放。
7. **适应窗口 / 实际大小 = 同一个比例尺的两个预设**：设计时统一按点（逻辑像素）处理，不追求实时真实尺寸；「适应窗口」把比例尺调到画布略小于视口（预览全局），「实际大小」把比例尺调到 1mm=8 点（真实打印比例），需要真实比例时再换算点与 mm。
8. **控件不可见根因（第三轮）**：Konva 9.3 的 `Text` 没有 `clipFunc` 方法，文本渲染抛异常导致 render 中断（网格先画好所以能看到网格、看不到元素）。改为用 Konva Group 的 `clipX/clipY/clipWidth/clipHeight` 裁剪；条码 / 二维码未绑定时显示「未绑定」虚线占位（不再渲染空白）。
9. **标尺画进 Konva（第三轮）**：HTML 标尺不随画布平移（放大后平移会错位）；改为把标尺绘制进 Konva layer（左上角空块 + 顶部 / 左侧刻度），与内容同坐标系，平移 / 缩放天然同步。
10. **中键平移修复（第三轮）**：改用原生 DOM + document 级 mouseup 复位（原 Konva 事件在鼠标移出画布后松键不触发，导致"松开还在拖"）。
11. **第四轮修复**：
    - 吸附 / 位置换算统一用 `getClientRect({ relativeTo: layer })` 逻辑坐标（原默认返回绝对视觉坐标，放大比例尺后吸附偏差 total 倍）。
    - 二维码改为同步 canvas 渲染（qrcode-generator 模块遍历 `getModuleCount / isDark` 手绘，去掉异步 Image 加载）。
    - 属性面板下拉 / 勾选缺 `commit()` 导致切换不刷新（条码底部文字、码制、纠错、文本模式等）——已补。
    - 边框 / 内边距改为**通用设置**（文本 / 条码 / 二维码一致）：边框 = 矩形边界是否显示；内边距 = 内容与边框的距离（内容绘制区域 = 框 - 内边距）。
    - 文本模式收敛为**「缩小适应 / 隐藏」**两种：文本框 = 遮罩区域，单行绘制，超出部分按设置缩小字体或隐藏（被遮罩裁剪）；抛弃自动换行 / 不限制高度。
12. **第五轮改进**：
    - 拉伸文本框只改变遮罩区域，**字高保持独立**（不再随框变大）；溢出模式文案改为「隐藏」。
    - 内边距拆为**左右内边距 / 上下内边距**（文本 / 条码 / 二维码通用）。
    - 填充**默认固定值**；切到「字段填充」显示**键名称（契约字段）**与**填充值（仅预览）**两个输入框——填充值用于画布预览，实际打印由外界数据按键名提供。
    - 新增 **Ctrl+C / Ctrl+V 复制粘贴**选中元素（粘贴偏移 5mm，自动选中新元素）。
13. **第六轮改进**：
    - **Ctrl+Z / Ctrl+Y 撤销与恢复**（含属性修改、移动、缩放、添加 / 删除、对齐、粘贴等操作，上限 100 步）。
    - 字高调整：**只有字高超过文本框当前高度才撑高文本框**，缩小字高不改框。
    - 吸附强化：阈值加大、参考线更醒目，两个控件边靠近时吸附到边完全重合。
    - **导出设计 / 导入设计**：把当前设计（纸张 + 元素）序列化为 `labelframe-web-design` JSON 复制到剪贴板（Ctrl+Shift+C / Ctrl+Shift+V，file:// 下受限时自动弹出提示框），程序更新后可从剪贴板恢复设计。
    - 控件栏新增**矩形**控件：可画矩形（边框 + 可选填充色），保存映射为版式 region（边框矩形）。
    - 文本框基础属性新增**高度**字段（遮罩高度，与条码 / 二维码一致，方便统一排版；字高仍独立）。
    - **吸附落点修复**：Konva 拖拽会用指针位置覆盖 dragmove 中的吸附，松手时坐标偏离（如目标 75,5 变成 74.1,4.9）；改为 dragend 时重新吸附一次再保存坐标，保证与参考线完全一致。
14. **第七轮改进**：
    - **矩形镂空**：矩形仅边框（内部透明，打印无背景色场景），移除填充色设置。
    - **图层面板**：左侧显示全部控件列表（z 序，后画的在上层），点击选中并同步画布（Shift/Ctrl 多选）；提供 **置顶 / 上移 / 下移 / 置底** 调整层级；列表选中后按 Delete 删除。
15. **第八轮修复**：
    - **网格吸附**：无边缘 / 中心参考目标时，松手自动把左上角贴到最近 1mm 网格（消除 0.2 之类的小数偏移，例如 24.8,4.8 → 25,5）；边缘 / 中心吸附仍优先。
    - **填充提示**：字段填充区明确提示「打印时从外界数据取键名称对应字段填充，预览值会被忽略」。
16. **第九轮改进（真实 DPI 打印预览）**：
    - 移除「适应窗口 / 实际大小」按钮，改为 **DPI 选择框（203 / 300 dpi）** + **「预览打印效果」按钮**。
    - 点预览：按所选 DPI 把当前内容换算成真实打印比例显示（203dpi → 1mm≈8 点、300dpi → 1mm≈12 点），可中键平移 / Ctrl+滚轮缩放；再点「退出预览」回到画布适应窗口。
    - **预览 = 纯打印效果（同界面，不弹窗）**：预览时隐藏网格 / 标尺 / 内容区边界线 / 选中框，元素不可选中、拖动、编辑（属性面板与图层面板显示"预览中"锁定提示，复制 / 粘贴 / 撤销 / 删除 / 添加均禁用）；退出预览后恢复。
    - **预览只显示标签范围**：预览画布去掉标尺区与 10mm 留白，仅显示宽高定义的标签内容（元素按标签坐标直接渲染），所见即打印。
## 功能对照（与 WPF 设计器 8D 对齐）

- 画布：毫米标尺 + 网格；左键选中、8 手柄缩放、Shift 多选、Delete 删除、中键平移、Ctrl+滚轮缩放。
- 属性面板：仅选中时显示；单选显示位置 / 尺寸 / 填充 / 字体 / 边框 / 文本溢出 / 条码二维码参数；多选显示对齐工具。
- 契约字段：由元素填充 Key 自动推导（左侧只读列表）。
- 保存：`POST /api/templates`；预览：`POST /api/templates/{name}/preview`（WinHost 渲染 PNG，真实打印效果）。
